三、需求追踪
REQ-001 前方 <=100 cm：在原有定高/光流飞行阶段进入持续保持，平移、偏航、垂直手势中立。
来源：用户确认。实现：shared/flight_feedback.h、飞控 HAL/hand_link.c。
有效范围沿用 20..720 cm、最近 600 ms 的 UART3 校验通过读数。
无效/超时前向读数禁止继续前进，不伪造后/左/右传感器。
离地起飞阶段保留原有上升/离地判定；进入定高后执行已锁存的避障保持。
主动 LAND/急停优先；高度丢失时沿用原有手动推力恢复，不声称仍能定高。
验收：100/101 cm 边界、无效读数、持续保持、起飞/降落/急停回归。

REQ-002 障碍解除：距离 >120 cm 连续 500 ms，且结束时有新的有效测距，才提供解除资格。
资格满足后，掌心按钮一次新的按下边沿发送 HC_CLEAR_OBSTACLE；飞控重新检查条件。
不用平放；提前按住不会排队等待解除。按住仍为原有中立手势，松开恢复当前手势。
原有“平放满 1 秒才发送前进”的手势识别逻辑保持，它不是解除避障的前置条件。
解除指令最多重发 300 ms，收到对应回复后结束；急停/飞行阶段变化立即取消重发。
丢包导致没有成功解除时再按一次；不会因为距离恢复自动继续飞行。
实现：shared/hand_protocol.h、手控 tx_control.c/telemetry.c、飞控 hand_link.c。

REQ-003 避障反馈：H6/GPIO5 低电平点亮，保持状态中每 250 ms 翻转（2 Hz 完整闪烁周期）。
MOT0/GPIO18 每次新障碍保持事件震动 3000 ms，持续障碍不重复延长。
REQ-004 倾斜反馈：飞机任意一轴 |pitch| 或 |roll| >30° 持续 200 ms 触发。
两轴均 <25° 持续 500 ms 才解除。检测在飞控 3 ms 周期，不使用手部角度代替飞机角度。
MOT1/GPIO17 每次倾斜事件震动 3000 ms。原有 >50° 保护保持，并回传硬倾斜故障提示。
REQ-005 两路互斥：倾斜优先；中断的避障震动保留剩余时长，倾斜结束后继续。
通用测试/弱通信提示不能覆盖正在执行的报警脉冲。软件 PWM 强度 80%，实物体感未验证。
实现：shared/haptic_policy.h、手控 vibration.c。看门狗周期 20 ms，报警不阻塞控制任务。

REQ-006 五路灯：通信灯 A 为新鲜、匹配会话的飞控回复；通信灯 B 为摄像头上传 ACK。
飞机回复 <300 ms 且不处于链路警告时 A 常亮；匹配上传 ACK <1000 ms 时 B 常亮。
其余三路分别表示有效 LEFT、RIGHT、DOWN 手势。DOWN 表示手势下降，不仅是 LAND 状态。
来源：已确认的功能方案。尚未确认：五路灯到上述五种用途的实物映射。
实现：led_demo.c 中 s_role_pins 按 [飞机通信, 相机通信, 左倾, 右倾, 下降] 排列，暂为 -1。
旧流水灯及掌心短按换灯效/长按关闭灯效已移除，掌心控制和两个独立飞行按键保留。

七、软件流程和协议
飞控 UART3 测距 -> 3 ms 策略更新 -> 指令入口中立/限制前进 -> 原生 PID 与电机混控。
飞机倾角 -> 200/500 ms 回差 -> 每个 HC3 回复共同状态位 -> 手控报警。
手控掌心按下 -> 校验新鲜解除资格 -> HC3 命令 6 -> 飞控再次检查 -> 回传对应结果。
HC3 STATUS channels[0] 新增：0x20 避障保持、0x40 可确认解除、0x80 倾斜报警、
0x100 前向测距无效、0x200 支持本次反馈功能。原解锁/定高/光流位不变。
飞控锁定、失联、射频故障沿用原有处理；保持不是额外的永久禁用避障开关。

九、逐灯识别与运行
