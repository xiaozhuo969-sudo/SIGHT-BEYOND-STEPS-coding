# ESP32-S3 GC2145 编译与烧录

当前固件使用 **GC2145 RGB565 采集、软件 JPEG 编码、双帧缓冲、纯热点观看模式**：开机建立无密码热点 `Camera-D6A4`，网页 `http://192.168.4.1/`（80 端口），视频流由网页访问 81 端口。80 端口同时接收手控制器每 300 ms 上传的参数，并推送给网页绘制。无需配网、无需路由器，不触发网络登录页跳转。硬件配置为 **8MB Flash + 8MB Octal PSRAM**，引脚见 `main/board.h` 和 `README.md`。

```bash
source /home/zhangnuo/esp/esp-idf-v6.0.3/export.sh
idf.py -C /home/zhangnuo/项目/接单项目/小飞机/相机 -B /home/zhangnuo/esp/builds/xiaofeiji-camera-s3 build
idf.py -C /home/zhangnuo/项目/接单项目/小飞机/相机 -B /home/zhangnuo/esp/builds/xiaofeiji-camera-s3 -p /dev/ttyACM0 flash
```

复用英文构建目录，因为本机工具链对中文构建路径有兼容问题。`idf.py flash` 写入引导、分区表和应用，但**不擦除整片 Flash/NVS**。旧路由器凭据仍在 NVS 中，当前固件不会读取；如以后重新烧录旧固件，它仍可能使用这些凭据。串口编号随连接变化时应先检查设备列表。

手机连接热点后如显示“无互联网”，保持连接，并在 Safari/Chrome 手动打开 `http://192.168.4.1/`。只允许一个视频观看连接；电脑测试完成后应关闭页面再让手机观看。旧的路由器地址 `192.168.0.107` 已不适用。
